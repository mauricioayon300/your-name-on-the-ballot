# Your Name on the Ballot

The local seats open for election in Pacific County, Washington in 2027, what each office does, and the minimum requirements to run.

Live page: https://mauricioayon300.github.io/your-name-on-the-ballot/

Companion to [One Name on the Ballot](https://mauricioayon300.github.io/one-name-on-the-ballot/). Published by Pacific County Voices Uniting.

The seat list is built from public filing records and is not the official list. Check with the Pacific County Auditor before filing.
